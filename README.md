# Sneak Flappy Bird

A polished cyberpunk-style landing page and game launcher experience built with plain HTML, CSS, and JavaScript.

## GitHub Pages
This site is ready to publish on GitHub Pages by uploading the files in this folder to a GitHub repository.

### Steps
1. Create a new repository on GitHub.
2. Upload these files to the repository root:
   - index.html
   - flappybird.html
   - particleBackground.css
   - particleBackground.js
   - styles.css
   - favicon.png
   - favicon.ico
   - assets/
3. Open the repository settings and enable GitHub Pages.
4. Use the main branch as the source.

Your site will be available at:
https://<your-username>.github.io/<your-repository-name>/
